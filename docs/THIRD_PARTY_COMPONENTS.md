# Third-party research components reviewed during the thesis

The original thesis workspace contained local copies of several external research projects. They are **not redistributed in this portfolio-safe repository**. This keeps authorship clear and avoids republishing datasets, model weights, or third-party code without an explicit licensing review.

| Component | Role in thesis workspace | Provenance visible in supplied workspace |
|---|---|---|
| 3DCNN-SM-LRP | PET / 3D CNN research component | Local research implementation; README references ADNI |
| AD-DL / ClinicaDL | MRI deep-learning framework | ARAMIS Lab ClinicaDL: https://github.com/aramis-lab/clinicadl |
| Alzheimers_Prediction_System | Clinical prediction component | https://github.com/arpy8/Alzheimers_Prediction_System |
| GPMKL | Feature-based Gaussian-process multikernel component | README describes it as an official paper implementation |
| gsp-alzheimer-detection | EEG / graph signal processing component | Mootoo et al. preprint: https://doi.org/10.1101/2023.11.01.23297940 |

## Important authorship note

HARMONI-AD's thesis contribution is the multimodal system design, orchestration, input validation, controlled handling of missing modalities, transparent status reporting, and evaluation of the integrated workflow. The underlying external research implementations should be credited to their original authors.
